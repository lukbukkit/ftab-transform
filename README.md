# FTAB Container Transform
Author: **Lukas Arnold**

_Provides container transforms for firmware in Apple's FTAB format._

## Description:
This plugin leverages the [Container Transform API](https://docs.binary.ninja/dev/containertransforms.html#manual-transform-selection) to extract members from Apple's custom firmware archive format FTAB directly in Binary Ninja.
